# Example: Jane Doe (fictional)

A made-up VP Engineering candidate, partway through the interview.

- `source/cv.md`: the CV she started with.
- `cv-evidence/`: the evidence base after the import, Phase A and the interview on her current
  role. The older role is still `imported`.
- `cv-evidence/exports/resume.vp.en.json`: JSON Resume export for the `vp` track.

Compare `source/cv.md` with `cv-evidence/roles.yaml` to see what the interview adds.
